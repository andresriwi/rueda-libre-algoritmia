# rueda-libre-algoritmia
Asistente de Taquilla - Rueda Libre
Descripcion del proyecto:
Proyecto desarrollado para la taquilla del emprendimiento Rueda Libre (Medellin). Automatiza el calculo de tarifas de alquiler de bicicletas urbanas, la cotizacion de recorridos guiados y la division equitativa de cuentas para grupos mediante logica secuencial
Algoritmos incluidos:
Los archivos se encuentran en la carpeta algoritmos/
cotizacion_basica.psc
Calcula el valor a cobrar por el alquiler de una bicicleta urbana por horas ($10.000 COP por hora), generando un mensaje personalizado para el cliente
cotizacion_recorrido.psc
Cotiza un recorrido guiado para un grupo de personas calculando el valor total, el anticipo de reserva obligatorio (30 %) redondeado al entero mas cercano y el saldo restante por pagar el dia del evento
cuenta_grupo.psc
Integra el alquiler combinado de varias bicicletas urbanas y recorridos guiados, aplica el aporte voluntario del 10 % para el mantenimiento de la flota y realiza la division de la cuenta por persona redondeando hacia arriba a la centena mas cercana para facilitar el cambio en efectivo
Instrucciones para abrir y ejecutar en PSeInt:
Instalar PSeInt en el equipo
Seleccionar el perfil Estricto para asegurar la validacion correcta de las variables definidas
Abrir los archivos
